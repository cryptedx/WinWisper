Dictation

Talk into any text field

Hold the hotkey and speak. A small capsule shows that WinWispr is listening, and the transcript lands where your cursor was: mail, chat, code editor or browser.

  • Hold to talk, or press once to start and again to stop
  • Personal dictionary for names and terms it gets wrong
  • German voice commands for paragraphs, new lines and bullets
  • Lost a paste? Ctrl Alt V puts it in again

Translation

German and English, both ways, offline

Select text and press Ctrl Alt E. WinWispr detects the language and shows the translation in a preview. Replace the selection, copy it, or swap the direction.

  • Speak German, get English: hold Shift Alt E
  • Selections up to 3,000 characters
  • The Opus-MT model runs on your PC, no account needed

Task board

Say a task, review it, done

A To Do, Doing and Done board with tags, due dates and Markdown notes. Dictate a task with Ctrl Alt T; it opens as a draft and is saved only after you check it.

  • Search, tag filters, sorting and drag between columns
  • A morning reminder for tasks that are due
  • Stored in one local file with a backup copy

Hotkeys

Six shortcuts, all changeable

These are the defaults. Each one can be changed in Settings, and dictation can run in Hold or Toggle mode.

Privacy

Your voice stays on your PC

Speech recognition and translation run locally. Once WinWispr Models is installed, the app needs no network access at all. After pasting, it restores what was on your clipboard.

Data lives in %LOCALAPPDATA%\WinWispr. The uninstaller asks before deleting it.

Install

Running in three steps

  1. Install WinWispr

    Run WinWispr-Setup-vX.Y.Z.exe from the latest release, or extract the portable ZIP to a folder of your choice.

  2. Add the models

    Run the WinWispr Models installer (about 870 MB) from its models-vN release once. It holds the speech model, the translation model and the voices.

  3. Hold and speak

    Pick your microphone in Settings, click into any text field and hold Shift + Alt + X.
